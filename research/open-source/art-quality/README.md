# LumaSprite Engine — Open-Source Art Quality R&D

[Open the standalone comparison and score sheets](LumaSprite-Engine-Art-Quality-RnD.html)

The research starts from Engine checkpoint `ba81037`. Use the existing Engine dependencies and Node 24 or later. This run used Node 26.13.1 on Windows x64. The three scripts run in order from the Engine root. They write their PNG strips, QA, timing and exact poses or geometry to `benchmarks/results/run/art-quality-rnd/`.

```powershell
node research/open-source/art-quality/verify.ts
node research/open-source/art-quality/report.ts
```

To regenerate a single experiment, run `ik.ts`, then `three-quarter.ts` or `color.ts` as needed. The verifier runs all three twice and compares PNG and JSON hashes except the timings of the benchmarks themselves. The HTML embeds the evidence from the latest run and includes downloadable technical data. Its performance values are a measurement snapshot. Use the exact frame durations in the R&D timing sidecar for playback.
