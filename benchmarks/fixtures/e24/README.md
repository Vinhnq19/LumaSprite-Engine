# E2.4 scene fixtures

All files are CC0 1.0. The benchmark reads this small local subset and runs offline.

| Fixture | Origin and preparation |
| --- | --- |
| Town grass, grass detail and path rows | Kenney Tiny Town 1.1, originals `Tiles/tile_0000.png`, `0001`, `0013`, `0025`, `0037`. PNGs copied unchanged from the author's OpenGameArt upload. [Kenney asset listing](https://kenney.nl/assets/tiny-town) |
| Dungeon floor, detailed floor and wall | Kenney Tiny Dungeon 1.0, originals `Tiles/tile_0000.png`, `0012`, `0014`. PNGs copied unchanged from the author's OpenGameArt upload. [Kenney asset listing](https://kenney.nl/assets/tiny-dungeon) |
| RPG traveler | Eldiran's `RPGCharacterSprites32x32.png`, exact 32×32 crop at x=32, y=288. The magenta key was replaced with transparent RGBA zero. [Author's OpenGameArt release](https://opengameart.org/content/32x32-rpg-character-sprites) |

The fixtures use one source pixel per benchmark pixel. [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
